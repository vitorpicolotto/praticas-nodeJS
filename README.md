# Práticas Node.js

Este projeto contém uma coleção de arquivos JavaScript para prática de conceitos fundamentais da linguagem, organizados em pastas temáticas.

## Estrutura do Projeto

```
praticas-nodeJS/
├── Arrays/
│   ├── array-for.js
│   ├── array-lista.js
│   ├── array-metodos.js
│   └── array.js
├── Condicionais/
│   ├── if-else.js
│   ├── lista-condicionais.js
│   ├── operadores.js
│   └── ternarios-e-switch-case.js
├── Funções/
│   ├── arrow-function.js
│   ├── callback.js
│   ├── exp-funcao.js
│   ├── function.js
│   └── lista-funcoes.js
├── Laços de Repetição/
│   ├── for.js
│   ├── lista-lacos.js
│   └── while.js
└── Objetos/
    ├── lista-objetos.js
    ├── objetos-metodos.js
    └── objetos.js
```

## Resumo

O projeto foi desenvolvido para praticar e demonstrar o uso de diferentes estruturas e conceitos em JavaScript, incluindo:

- **Arrays**: Manipulação de arrays, métodos comuns e iteração.
- **Condicionais**: Estruturas de controle como if-else, operadores lógicos e switch-case.
- **Funções**: Declaração de funções, arrow functions, callbacks e expressões de função.
- **Laços de Repetição**: Loops for e while para repetição de código.
- **Objetos**: Criação e manipulação de objetos, métodos e listas de objetos.

Cada pasta contém arquivos específicos com exemplos práticos dos respectivos tópicos.
